# 🚗 Car Price Prediction and Analysis Project

## 📌 Overview
This project is a **Machine Learning-based Car Price Prediction System** built using Python, Streamlit, and data analysis techniques.  
It predicts the price of a car based on features like horsepower, engine size, mileage, weight, and other specifications.

---

## 🎯 Objective
- Analyze car dataset
- Perform data cleaning and preprocessing
- Build ML regression models
- Compare different models
- Deploy interactive web app using Streamlit

---

## 🧠 Machine Learning Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Hyperparameter tuning (GridSearch / RandomSearch)

---

## 📊 Features Used
- Year
- Engine Size
- Horsepower
- MPG (City & Highway)
- Weight
- Wheelbase
- Length

---

## 🛠️ Tech Stack
- Python 🐍
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib / Seaborn
- Pickle

Successfully built regression model for car price prediction
